# El Segfredo – Entwickler-Seite

Adresse: **https://elsegfredo.github.io/**
Gehört zur GitHub-Organisation **elsegfredo**, Repository **elsegfredo.github.io**.

Projekte, Team, Neuigkeiten und der Bereich **Zusammenarbeit** mit Kontakt. Impressum und Datenschutzerklärung hier gelten auch für die Spielseite https://bulbfight.github.io/ und die Instagram-Accounts @elsegfredo und @bulbfight.

Kostenlos: GitHub Pages, keine Domain nötig. Keine Cookies, kein Tracking, nichts wird von fremden Servern geladen.

## Einmal einrichten (Schritt für Schritt)

1. **Organisation anlegen:** Auf github.com angemeldet als `liviuweb` oben rechts auf dein Profilbild → *Your organizations* → *New organization* → Plan **Free** → Name **`elsegfredo`**. Bei „This organization belongs to“ *My personal account* wählen.
2. **Repository anlegen:** In der Organisation *New repository* → Name genau **`elsegfredo.github.io`** → Public → *Create*.
3. **Dateien hochladen:** *uploading an existing file* bzw. *Add file → Upload files* → alle Dateien dieses Ordners markieren (Cmd+A) und hineinziehen → *Commit changes*. Es gibt keine Unterordner, das klappt also auch mit Safari.
4. **Pages einschalten:** *Settings → Pages* → Source *Deploy from a branch* → Branch **main**, Ordner **/ (root)** → *Save*. Nach ein bis zwei Minuten ist https://elsegfredo.github.io/ online.
5. **HTTPS:** In *Settings → Pages* den Haken bei *Enforce HTTPS* setzen (meist automatisch).

## Pflichtangaben

Name, Anschrift (c/o Block Services, Fellbach) und E-Mail-Adressen sind eingetragen. Wenn sich etwas ändert (z. B. neuer Adressservice): `impressum.html` und `datenschutz.html` direkt auf github.com bearbeiten (Datei öffnen → Stift-Symbol → *Commit changes*).

Den Impressum-Service nicht kündigen, solange die Seiten oder die Instagram-Accounts online sind.
